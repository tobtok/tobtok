# tobtok

Builder of Telegram directory tooling and customer-service infrastructure
for the Telegram ecosystem.

## Projects

- **[navsou.com](https://navsou.com/)** — a live Telegram group & channel
  directory, rebuilt every 15 minutes from an automated data pipeline.
- **[tgnav-lite](https://github.com/tobtok/tgnav-lite)** — the open-source
  static site generator behind navsou.com. JSON in, SEO-ready static HTML out
  (pagination, client-side search, sitemap sharding).
  [Live demo](https://tobtok.github.io/tgnav-lite/).
